        How your keys are protected

        • Stored securely: .
        • Write-only: once saved, a key is never sent back to this page. Only its last four characters are shown.
        • Verified before saving: keys are checked with a free model-list request. Invalid keys are not stored.
        • Least privilege: a scan receives only the selected provider’s key, through its environment, never on a command line, in logs, history or reports.
        • Environment wins: keys set as environment variables (for example ANTHROPIC_API_KEY) take priority and can’t be changed here.
        • Local only: the dashboard listens on 127.0.0.1 and accepts requests only from this page (per-session token, host, origin and fetch-site checks, strict content security policy).
